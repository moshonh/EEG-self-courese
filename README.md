# לומדת EEG בעברית — גרסה ראשונה

שני פרקים, 13 יחידות לימוד, איורים מהקבצים שסופקו ו־15 שאלות לכל פרק. השאלות והתשובות מתערבלות בכל ניסיון. הגשה דורשת מענה מלא; לאחריה מוצגים ציון, הסברים והפניות לעמודים ולאיורים. התוכן הוא עיבוד לימודי של הספר ונועד לבדיקת עורך רפואי לפני שימוש בהערכת מתמחים.

## הפעלה מקומית

נדרש Python 3.11 ומעלה. מתוך תיקיית הפרויקט:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python make_code.py
```

שמרו את קוד הכניסה שהודפס. צרו קובץ `.streamlit/secrets.toml` והדביקו בו את מקטע ה־TOML שהודפס. לאחר מכן:

```powershell
.venv\Scripts\python -m streamlit run app.py
```

אין קוד ברירת מחדל. אפשר להגדיר כמה ערכי SHA-256 במערך code_hashes. הקוד עצמו אינו נשמר בקבצי המקור. זו כניסה בקוד משותף או כמה קודים, ללא חשבונות אישיים, זיהוי מתמחה או שחזור סיסמה. ההשהיה בין ניסיונות היא ברמת החיבור ואינה תחליף להגבלת קצב מרכזית.

## העלאה ל־Streamlit Community Cloud

1. העלו את תיקיית הפרויקט למאגר GitHub פרטי, כולל assets ו־course.json. אין להעלות secrets.toml.
2. ב־Streamlit Community Cloud צרו אפליקציה מהמאגר ובחרו app.py כקובץ הראשי.
3. ב־Advanced settings / Secrets הדביקו את מקטע access שהופק ב־make_code.py.
4. פרסמו ושתפו את כתובת האפליקציה ואת הקוד בנפרד. אם מוגדרת גם הגבלת גישה של Streamlit, יש להסדיר אותה בהתאם לקהל המתמחים.

הפרויקט מוכן להעלאה, אך לא פורסם מהסביבה הזו ולא נוצר חשבון אירוח. התהליך מתואר ב[תיעוד Streamlit](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app) וב[ניהול סודות](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management).

## תוכן ואיורים

המקור: שני הקבצים פרק 1.pdf ופרק 2.pdf מתוך Practical Approach to Electroencephalography, עם הודעת זכויות Elsevier 2017. מספרי העמודים בתוכן הם המספרים המודפסים בספר, לא מיקום העמוד בקובץ PDF. האיורים נחתכו מתוך העמודים המקוריים; סימוני המקור נשמרו, וטקסט הפתרון שמחוץ לתרשים הוסר בשאלות. האיורים לא תורגמו או צוירו מחדש; ההסברים והממשק בעברית.

לפני הפצה למתמחים יש לוודא הרשאה לשימוש באיורים ובחומר המוגן; רישיון אישי לקובץ אינו בהכרח הרשאה להפצה בלומדה. המקור כולל סיווג היסטורי של שלבי שינה; הלומדה מציינת במפורש מתי שאלה מתייחסת לסיווג הספר. אין כאן עדכון עצמאי של הנחיות דירוג שינה.

## המשך פיתוח

התוכן מופרד למבנה JSON: chapters מכיל יחידות, ו־questions מכיל שאלות, תשובות, הסברים, מקור ואיור אופציונלי. כדי להוסיף פרק, מוסיפים אותו ואת 15 השאלות שלו באותו מבנה ואת התמונות ל־assets.

התקדמות וציונים נשמרים ב־Session State במהלך החיבור בלבד. אפשר להוריד את תוצאת המבחן כ־JSON. אין מסד נתונים, לוח מנהל, רישום ציונים מרכזי או מעקב אישי בין כניסות. לצורך אלה יש להוסיף זיהוי מתמחים ואחסון מתמשך. לא הוגדר ציון מעבר, מכיוון שלא נמסרה מדיניות הערכה.
